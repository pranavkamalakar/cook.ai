# Cook.AI

An AI-powered cooking companion that generates recipes and provides step-by-step cooking guidance.

## Live Demo

Hosted on Vercel: **[https://cook-ai.vercel.app/](https://cook-ai.vercel.app/)**

## Features

- AI recipe generation using Groq
- Step-by-step cooking mode
- Save favorite recipes
- Responsive design with dark mode
- Region-aware localized recipe suggestions
- YouTube video cooking tutorials

## Tech Stack

- TypeScript + Vite
- Tailwind CSS
- Groq API
- Vercel hosting

## For Developers

```bash
# Clone repository
git clone https://github.com/pranavkamalakar/cook.ai.git
cd cook.ai

# Install dependencies
npm install

# Add your Groq API key to .env
cp .env.example .env

# Run locally
npm run dev
```
