# Cook.AI

An AI-powered cooking companion that generates recipes and provides step-by-step cooking guidance.

## Live Demo

**[https://cook-ai-app.netlify.app/](https://cook-ai-app.netlify.app/)**

## Features

- AI recipe generation using Groq
- Step-by-step cooking mode
- Save favorite recipes
- Responsive design

## Tech Stack

- TypeScript + Vite
- Tailwind CSS
- Groq API
- Netlify hosting

## For Developers

```bash
# Clone repository
git clone https://github.com/yourusername/cook-ai.git
cd cook-ai

# Install dependencies
npm install

# Add your Groq API key to .env
cp .env.example .env

# Run locally
npm run dev
```
